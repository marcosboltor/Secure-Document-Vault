# keys/

This directory is the default location for user keystore files generated by the Secure Document Vault.

Keystore files are JSON files encrypted with ChaCha20-Poly1305 using a password-derived key (PBKDF2-HMAC-SHA256, 600,000 iterations). They contain no plaintext private key material.

## File naming convention

```
<user_id>_encryption.json   # Encrypted X25519 private key
<user_id>_signing.json      # Encrypted Ed25519 private key
<user_id>_bundle.json       # Full keystore bundle (both keys)
```

## Security notice

**Never commit real keystore files to version control.**  
The `.gitkeep` file keeps this directory tracked by git while keeping it empty.  
Add your keystore files to `.gitignore` if you store them here locally.

## Usage

Keystores are created and managed via `KeyProtector` in `src/secure_document_vault/modules/key_store/generator.py`:

```python
from secure_document_vault.modules.key_store.generator import KeyProtector

# Save a keystore to this directory
KeyProtector.backup_keystore(keystore_dict, "keys/alice_encryption.json")

# Load it back
keystore = KeyProtector.restore_keystore("keys/alice_encryption.json")
```
